# ✅ 反馈自查清单

提交反馈之前，花 **1 分钟** 过一遍这份清单，能显著提高被处理的速度。

> 原则：**信息越全，处理越快。** 一次到位的反馈，比反复打回补充要省时得多。

---

## 一、通用（所有类型都查）

- [ ] 我已搜索仓库，确认**没有重复**的内容（避免被标 `duplicate` 关闭）
- [ ] 标题遵循 **`[应用名] 一句话描述`** 格式（如 `[相册] 备份后部分照片未同步`）
- [ ] **项目名字**选对了（OmniEdit - 随心编辑器 / Shortcuts - 快捷图标）
- [ ] **模板**选对了（问题反馈 / 建议反馈）

## 二、问题类

- [ ] 有清晰的**复现步骤**（1 → 2 → 3，别人能照着做）
- [ ] 写明了**预期行为** vs **实际行为**
- [ ] 写明了**发生频率**（必现 / 偶发）
- [ ] 附上了**截图 / 录屏 / 日志**

## 三、建议类

- [ ] 说清了**现状**（现在哪里不够好）
- [ ] 说清了**期望**（希望变成什么样）
- [ ] 说清了**理由 / 使用场景**（为什么值得做）
- [ ] 如有参考（别的软件做得好），已举例或配图

---

## 提交后的小贴士

- 留意 Issue 上的 `status: 待反馈` 标签：那是**需要你补充信息**，请及时回复。
- 有人 @ 你时，说明需要你确认或补充，请尽量在 **3 天内**响应。
- 如果问题已解决，可以留言说明，便于维护者关闭。
